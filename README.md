# 🎸 Violão Iniciante

Um site criado para ajudar pessoas que estão começando a aprender violão e não sabem por onde começar.

## 📌 Sobre o projeto

É comum que quem está começando a aprender violão encontre muitas informações diferentes na internet e acabe sem saber qual deve ser o primeiro passo.

O **Violão Iniciante** foi desenvolvido com o objetivo de oferecer um caminho simples e organizado para quem está começando.

O site apresenta os primeiros conhecimentos necessários para iniciar os estudos, desde as partes do instrumento até os primeiros acordes e uma sugestão de música para praticar.

## 🎯 Objetivo

O principal objetivo do projeto é **facilitar os primeiros passos de quem está aprendendo violão**, organizando os conteúdos de forma simples e progressiva.

## 📚 Conteúdos

O site possui algumas páginas principais:

* 🏠 **Início** — Apresentação do projeto e orientação para começar.
* 🎸 **Violão** — Explicação sobre as partes do violão e suas cordas.
* 🎵 **Acordes** — Apresentação de acordes básicos para iniciantes.
* 🎶 **Músicas** — Sugestão de uma música simples para colocar os conhecimentos em prática.

## 💻 Tecnologias utilizadas

* **HTML5** — Estrutura das páginas.
* **CSS3** — Estilização, cores, layout e responsividade.

> O projeto foi desenvolvido utilizando apenas HTML e CSS, sem JavaScript.

## 🎨 Design

O site utiliza uma identidade visual baseada em **tons escuros e laranja**, buscando transmitir uma aparência moderna e relacionada ao universo musical.

Também foi desenvolvida uma logo própria para representar o projeto.

## 📱 Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, utilizando **CSS e Media Queries** para adaptar o conteúdo a dispositivos menores, como celulares e tablets.
